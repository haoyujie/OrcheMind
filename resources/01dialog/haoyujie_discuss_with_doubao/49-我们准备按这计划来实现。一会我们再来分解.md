# 核心前置对齐
> 进化式迭代思路：**冻结当前层结构，只增量扩展，永不推倒重来，每一步状态持久化保存**，非常适合单人开发、算力有限的场景。
你定义的两阶段本体构建：
- **阶段A（初代本体：裸图）**：只有Node（节点，无端口/属性） + Link（连线，无类型），只记录连接关系，**纯拓扑网络，固化结构**。不做向量、不做训练，就是一张静态图。
- **阶段B（二代本体：增加Link类型、Node端口）**：给Link增加方向、谓词类型（RCC8、因果、归属等动词）；Node为每一类Link分化出独立port（接口）；这一步才把关系动词、范畴簇接入进来，后面再接向量/角度嵌入。


> 关键好处：每一轮迭代快照保存，失败可以回滚，不需要全部重算；完美适配单人+有限算力。

# 三、分步执行：阶段A（v01_raw_graph：裸Node+Link，无端口、无类型）
目标：只建拓扑网络，固化v01快照，**不涉及向量、不涉及训练**。
1. 定义最简单数据模型（pydantic，JSON持久化）
    - Node：`id:str, name:str`，**没有端口，没有属性**，就是圆圈
    - Link：`id:str, source_id:str, target_id:str`，只有起点终点，**无方向、无类型**
2. 录入本体基础节点
    - 顶层节点：康德4大类（量、质、关系、模态）
    - 下层节点：12个范畴节点
    - 继续往下：RCC8的8个关系节点、实体节点（通孔、焊盘等，先随便少量示例）
3. 建立Link：只写谁和谁相连，不标记关系动词。
    例：`Node["空间范畴"]` ——Link——> `Node["RCC8-NTPP"]`
4. 校验：用networkx加载图，检查连通性，检查重复节点/重复连线。
5. **固化快照**：把`data/graph`全部复制到`snapshot/v01_raw_graph`，写入版本说明文档。
> ✅ 到此阶段A完成，这一步纯数据录入，**完全不需要GPU，不需要训练**。随时可以回滚。

# 四、阶段B（v02_typed_link：增加Link类型 + Node端口Port）
基于v01快照，**增量修改，不改动原有节点和连接拓扑（进化原则：旧结构冻结）**
1. 扩展模型：
    - Link新增字段：`link_type:str, directed:bool`，link_type就是谓词ID（`穿过`、`包含`等），directed标记单向/双向。
    - Node新增Port：port绑定在node上，一个port对应一类link类型。
      > 含义：Node上的Port就是接口；某一类Link只能接入对应Port。
2. 增量更新：给已有的Link补充类型与方向；给Node生成对应Port。
    > 原有Node/Link拓扑结构**保持不变**，只增加新字段，不是重写图。
3. 谓词绑定：把RCC8、因果、归属动词分配给link_type；把谓词归入对应的范畴簇。
4. 导出OWL/Turtle，放到远端Mac用Protégé打开校验本体逻辑。
5. 再次固化快照：`snapshot/v02_typed_link`。
> 阶段B结束，你就拥有完整可校验的本体Schema。**仍然没有开始训练，没有向量嵌入**。
