# 三个：PIC、MEPIC、KVLink（精简版，RoPE视角）
三者目标一致：**把文档/代码块预先算好KV，跨不同query、不同位置复用，砍掉重复prefill开销**；差别在解决的痛点、内存管理、精度补偿方案。

## 1. PIC（Position Independent Caching，位置无关缓存，基础原型）
**核心思想**
把文本切成独立chunk（代码文件、文档段落），**单独预计算每个chunk的KV，剥离RoPE位置相位**。
使用的时候，把多个chunk的KV拼接到新序列，**根据这个chunk在新上下文里的全局pos，重新施加RoPE旋转**，直接复用语义KV本体。

- 优点：原理最简单，证明了“KV可以脱离原始pos复用”。适合RAG、代码库查询这类大量重复静态文本场景。prefill算力大幅下降。
- 短板：
  1. 拼接不同chunk后，**块与块之间的跨块注意力会失真**，精度掉得明显；
  2. 内存管理粗糙，每个请求会生成略有差异的KV副本，HBM显存复用率不高；
  3. 部分token需要重新计算做精度补偿，补偿粒度是token级，开销偏高。

一句话：**PIC是理论原型，证明这件事可行；但显存效率、精度补偿做得比较粗。**

## 2. MEPIC（Memory-Efficient PIC，内存优化版PIC）
MEPIC是PIC的工程改进版本，全称 Memory-Efficient Position Independent Caching。
**核心改进点（专门解决PIC显存浪费问题）**
1. **页对齐KV存储**：所有预计算的chunk KV统一分页存储，多用户/多请求**完全共享同一份显存副本**，不再每个请求单独存一份KV，HBM利用率大幅提升。
2. **块级补偿，而不是token级**：只需要对chunk的**第一个block做少量重计算**，chunk内部其余token全部直接复用，减少补偿开销。
3. RoPE融合进attention kernel，在线动态修正旋转相位。

- 优点：**显存节约是最大亮点**，适合大规模多并发服务（很多人同时查询同一个代码库/知识库）。精度损失控制比原版PIC好很多。
- 短板：内核改动更深，要修改paged kv cache底层，vLLM/SGLang集成难度更高；跨chunk边界依然有精度衰减。

一句话：**MEPIC = PIC + 分页共享内存，面向云端大规模并发推理优化。**

## 3. KVLink（独立的PIC路线，NeurIPS 2025）
KVLink 是另一套独立方案，不是PIC的衍生，思路略有区别。
**核心思想**
文档chunk离线预计算KV；拼接多个chunk到新上下文时，动态调整RoPE相位。
**最关键特色：引入可训练的特殊连接token，放在各个chunk之间**，专门修复跨块之间的注意力断裂问题。

- 原理：
  普通PIC拼接后，A块的token和B块token之间的attention因为分开预计算，相关性不准。
  KVLink在chunk之间插入少量专用训练token，学习不同文档块之间的关联，修复跨块注意力，**精度显著高于原版PIC（论文平均提升约4%）**。
- 优点：跨块推理质量更好，RAG、代码多文件联合查询场景表现强；TTFT（首token延迟）最高可以降到原来1/25。
- 短板：
  模型需要**微调，学习这个特殊连接token**；原生Qwen/Llama权重不能直接拿来用，需要额外训练。

一句话：**KVLink靠训练特殊分隔token解决跨chunk注意力失真，精度最好；代价是模型要微调。**

# 极简横向对比表
|方案|定位|核心手段|是否需要微调|最大优势|主要短板|
| ---- | ---- | ---- | ---- | ---- | ---- |
|PIC|基础原型|KV与RoPE相位解耦，动态重旋转|❌不用微调|原理简单，容易验证|显存复用差，跨块精度掉得多|
|MEPIC|PIC工程优化|分页KV全局共享，块级补偿|❌不用微调|显存利用率高，适合大规模并发|内核改动大，跨块仍有衰减|
|KVLink|独立路线|预计算KV + 块间可训练连接token|✅需要微调|跨chunk注意力精度最高|需要微调模型，部署成本高|

# 和你前面设想的架构搭配
上层MCP做两件事：
1. 向量检索，判断新query和历史代码块是否相关；
2. 调度：挑选哪些chunk加载进推理引擎。

底层推理引擎三选一：
- 做小规模本地实验：原版PIC（最简单）
- 云端高并发服务：MEPIC（省显存）
- 多代码文件联合推理、对精度敏感：KVLink（需要微调模型）

## 重要共同限制（三者都逃不开）
1. **只能复用静态文档/代码片段的KV**；**不能复用模型推理的中间残差、思考过程**。每一次新query的推理链条，仍然要动态跑。
2. 都**不会生成静态全局知识地图**，语义表征是预存的KV块，但位置相位每次使用动态计算。
3. 跨chunk边界的长距离注意力，始终存在精度损耗，只是三种方案损耗大小不同。
