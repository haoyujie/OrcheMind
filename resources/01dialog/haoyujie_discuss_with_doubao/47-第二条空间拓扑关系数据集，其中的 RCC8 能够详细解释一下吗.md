# 一、RCC8（Region Connection Calculus，区域连接演算）
RCC8 是一套**定性拓扑逻辑**，1992年提出，专门描述**两个面状区域**之间纯粹拓扑关系（不关心坐标、距离、角度大小，只关心连通、重叠、包含），**8个关系是互斥且完备**：任意两个区域，一定恰好属于其中一种关系。

> 非常适配你的PCB场景：焊盘、通孔、铜皮、信号层都可以抽象成二维区域。

### 8个基础谓词（附PCB例子）
|代号|全称|中文|PCB例子|
|---|---|---|---|
|DC|DisConnected|相离|通孔 和 远处焊盘完全不接触|
|EC|Exte$\boldsymbol r$nally Connected|外切/边界接触|两个焊盘刚好边界碰到，内部不重叠|
|PO|Pa$\boldsymbol r$tially Ove$\boldsymbol r$lapping|部分相交|铜皮一部分覆盖焊盘，一部分在外|
|EQ|Equal|完全等同|两个完全重合的同尺寸焊盘|
|TPP|Tangential P$\boldsymbol r$ope$\boldsymbol r$ Pa$\boldsymbol r$t|正切真子集（A贴边界包含于B）|焊盘在信号层内部，焊盘边缘刚好贴信号层边界|
|TPPi|TPP inve$\boldsymbol r$se|TPP的逆（B贴边界包含A）|信号层包含这个贴边界的焊盘|
|NTPP|Non-Tangential P$\boldsymbol r$ope$\boldsymbol r$ Pa$\boldsymbol r$t|非切真子集（A完全在B内部，不碰边界）|通孔完全落在焊盘内部，通孔边缘碰不到焊盘外圈|
|NTPPi|NTPP inve$\boldsymbol r$se|NTPP逆（B完整包含A，不碰边界）|焊盘完整包裹通孔，通孔不触碰焊盘边界|

关键点：
1. RCC8自带**组合推理表（composition table）**：已知A-R1-B，B-R2-C，可以直接推导出A和C可能的拓扑关系集合。这就是本体推理能力。
    > 例：A NTPPi B（B完整包含A），B NTPPi C → C一定完整包含A。
2. 它是**逻辑本体Schema，不是训练数据集**。
    - 你可以把RCC8的8个谓词，作为你圆环上**空间簇的基础动词**；
    - 但RCC8本身不带大量自然语言样本，**没有现成的实体三元组训练集**；
    - 开源资源：OWL/Tu$\boldsymbol r$tle本体文件，可以直接下载，OpenKG、p$\boldsymbol r$otege本体工具生态原生支持。
3. 局限：只描述**面区域拓扑**，不描述方向、距离、因果、归属。只对应康德范畴里【协同性（共存）】这一小类。

> 对你的架构的用法：
> 把RCC8这8个作为空间簇的核心基础谓词；再扩展衍生动词（穿过、贯穿、穿透），归入同一空间簇，分配到圆环同一个扇区。

# 二、Wo$\boldsymbol r$dNet + WN18RR + RotatE（你前面提到的这套）
## 1. Wo$\boldsymbol r$dNet
英文词网，词典本体。把单词组织成同义词集合（synset），自带词汇关系：`pa$\boldsymbol r$t-of（组成）、instance-of（实例）、hype$\boldsymbol r$nym（上位词）`。
> 它是**词汇本体**，不是专门空间拓扑本体。

## 2. WN18RR
**Wo$\boldsymbol r$dNet抽出来的标准知识图谱三元组数据集**，是知识嵌入领域最经典的基准数据集。
- 实体：Wo$\boldsymbol r$dNet里面的词义集合（单词概念）
- 关系：一共**11种固定关系**（pa$\boldsymbol r$t of、membe$\boldsymbol r$ of、simila$\boldsymbol r$ to等）
- 样本：十几万条 `(头实体,关系,尾实体)` 三元组
- 注意：原始WN18有大量反向关系造成数据泄露；WN18RR是清理后的版本，删掉了简单逆关系，作为标准benchma$\boldsymbol r$k。

> 一句话：**WN18RR是一份训练用的三元组数据，不是模型**。

## 3. RotatE模型（就是在WN18RR上训练的模型）
RotatE：Knowledge G$\boldsymbol r$aph Embedding by Relational Rotation in Complex Space
> 核心思想**和你现在的设计高度同源**：
> 实体映射成复数向量；**关系 = 在复平面上的一个旋转（角度）**。
> 公式：$\boldsymbol h \ci$\boldsymbol r$c \boldsymbol $\boldsymbol r$ \app$\boldsymbol r$ox \boldsymbol t$，$\boldsymbol $\boldsymbol r$$是复数，代表旋转角度。
> 也就是：头实体向量，经过关系对应的角度旋转，得到尾实体向量。
> 可以自然建模对称、反对称、逆关系、组合关系，正好对应你在单位圆上放置关系动词的思路。

### ✅ 能不能直接拿来用？分两层说
1. **数据集WN18RR：可以直接下载，开源免费**
    可以拿来跑原型，提取谓词、做聚类，PyKEEN、DGL-KE等库一键加载。
    但是：**它只有11种关系，数量太少，而且大部分是词汇/分类关系，PCB空间拓扑关系几乎没有**。只适合做算法原型验证，不能直接当你的工业本体谓词库。

2. **预训练好的RotatE权重：可以直接加载，拿来做推理**
    PyKEEN库自带预训练RotatE权重，在WN18RR上训练完成。
    - 你可以直接读取：实体向量、关系对应的复数旋转向量（角度）；
    - ⚠️但是**不能直接拿来做你的PCB本体**：
        - 它的关系空间是Wo$\boldsymbol r$dNet的词汇语义，不是PCB拓扑；
        - 它的角度/向量空间是模型自由学出来的，**不是人工Schema预先定义的圆环布局**；
        - 它没有“簇原型”，没有你设计的$L_{int$\boldsymbol r$a}/L_{inte$\boldsymbol r$}$簇约束，训练会打散语义邻近关系。
> 重点区分：
> RotatE的数学机制可以**借鉴**（关系作为复平面旋转），但**预训练权重不能直接复用进你这套带人工Schema约束的本体系统**，需要重新训练。

# 三、RCC8 和 WN18RR+RotatE 的对比（对你的项目）
|RCC8|WN18RR+RotatE|
|---|---|
|定性拓扑逻辑本体，8条基础谓词|词汇知识图谱数据集+复数旋转嵌入模型|
|人为定义的严谨逻辑，适合Schema层|从文本数据自动学习语义向量|
|适合PCB空间关系（穿过、包含、相交）|适合通用词汇分类、从属关系|
|没有大量三元组训练样本，需要你自己生成|自带十几万三元组，开箱就能训练|
|可控、可解释，符合你的“人主导Schema”|隐空间自动学习，不可控，会破坏预先定义的簇|

# 四、工程上怎么组合使用（贴合你的整套架构）
1. 拿 **RCC8** 作为顶层Schema原型，定义空间范畴簇，8个基础谓词作为簇内核心；再扩展`穿过、贯穿、穿透`等工程动词归入该簇。
2. 拿 **Wo$\boldsymbol r$dNet** 做同义词聚类，合并近义词动词。
3. 拿 **WN18RR + RotatE** 的**数学框架（复数旋转嵌入）**作为你模型的底层实现方案；**不要直接加载它预训练权重**。
4. 自己构造PCB领域三元组数据集（实体A，RCC8/扩展动词，实体B），使用我们前面设计的4项Loss+残差链路，**从头训练你的本体嵌入模型**。

# 补充一个关键提醒
RotatE原生没有**残差链路**，也没有簇原型与簇内/簇间损失。它只是单纯的KG嵌入模型。
所以数学思想可以借鉴，但模型架构必须按我们前面讨论的，增加残差、簇原型、保真loss，才满足你“父层Schema不能被子代训练覆盖”的目标。
