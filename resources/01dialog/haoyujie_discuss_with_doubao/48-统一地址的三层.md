# 核心确认（先回答你最关键的判断）
> 现代Transformer（RoPE位置编码、RotatE这类KG嵌入）和傅里叶级数/傅里叶变换**数学内核是相通的**，但不是完全等同；**当下所有主流大模型都没有跳出这套线性叠加、基函数分解的表征范式**。
- 傅里叶：用一组固定正交基（不同频率正弦/余弦）线性叠加，逼近任意信号/轮廓；频率越高，细节越精细。
- RoPE：本质就是复数域离散傅里叶的局部相位旋转，把位置信息分解到不同频率子载波；高频分量负责精细局部特征，低频负责全局粗特征，和你说的“用傅里叶画地图”逻辑完全一致。
- RotatE：把关系作为复平面旋转算子，也是基于复数三角函数（和傅里叶基同源）。

⚠️ 但是有一个重要边界：
傅里叶是**固定基**；LLM是**可学习基**。傅里叶的基函数预先写死；Transformer的基（注意力头、MLP权重）是数据学出来的。**但二者都是在高维空间用一组基的线性组合去表征事物**，所以可以建立统一地址空间。
你的判断成立：**理论上可以打通【人工定义的范畴Schema系统】和【Transformer类大模型】，共用一套同源的向量/角度编码体系**。

# 整体架构规划（两套Schema子系统 + Transformer模型，统一地址体系）
Schema层包含两个子系统（你说的，一套人工定义、不需要训练；另一套是范畴粗检索模型）
1. **Schema子系统A：人工本体定义系统（无训练，纯声明式）**
    - 内容：康德12范畴顶层分类 + 谓词（关系动词）词表 + RCC8这类基础关系 + 预先分配的角度/复平面坐标。
    - 特点：**人说了算，固定规则，不通过梯度训练修改**。
    - 输出：每个谓词、每个范畴簇的初始向量（复平面角度）、簇原型向量、簇边界约束。
    - 作用：定义“地基”，规定哪些关系属于同一簇、簇之间的语义距离。

2. **Schema子系统B：范畴粗检索模型（轻量，可微调，保护A的地基不被推翻）**
    - 内容：残差链路 + 四项联合损失（$L_{task},L_{intra},L_{inter},L_{alignment}$）。
    - 特点：**不能大规模重排A定义好的向量，只能做微小增量修正**；增量做幅度裁剪。
    - 输出：对齐后的谓词向量、动态更新的簇原型；输入文本/实体对，快速检索所属范畴簇。
    - 作用：作为A和大模型之间的适配层，把自然语言映射到本体空间，同时维持本体拓扑。

3. **第三组件：Transformer大模型（可以直接使用开源权重，如千问）**
    - 作用：细粒度推理、自然语言理解、代码生成、复杂逻辑推演。
    - 对齐：通过对齐投影矩阵$W_{align}$，把大模型token嵌入映射到本体复平面向量空间；反过来本体向量也可以投影进LLM的表征空间。
> 向量空间不一定是单一空间：本体侧可以是二维复数空间（RotatE/RoPE风格），LLM是高维嵌入空间，依靠**投影矩阵**建立跨空间统一寻址，不需要强行合并成同一个维度。

# 分阶段落地规划（工程顺序，由简到繁，最小原型先行，避免一次性投入巨大工作量）
> 原则：**先跑通最小验证原型，再逐步扩容；不要一开始就做完整通用系统**。一共4个阶段。

## 阶段0：准备工作（当前阶段，你现在就可以动手准备，纯资料/脚本，不需要训练大模型）
目标：定义Schema本体，构建基础谓词库
1. 顶层范畴定义：把康德12范畴作为顶层分类，建立分类树。
2. 基础谓词收集：
    - 空间关系：RCC8 8个基础关系，扩展工程动词（穿过、贯穿、包含等）
    - 补充：归属、因果、模态、比较类谓词，从WordNet、Wikidata、OpenKG提取中文谓词
3. 同义词聚类：调用开源LLM（千问本地部署）对谓词做同义合并，划分簇。
4. 复平面角度初始化：
    - 每个簇分配复平面上一段连续扇区；
    - 簇内每个谓词分配初始角度，同簇角度邻近；
    - 计算每个簇的初始原型向量（簇内向量均值）。
输出产物：本体JSON文件（范畴树、谓词列表、簇划分、初始角度、簇原型）。
> 这部分就是Schema子系统A，**完全人工定义，不需要训练**。

## 阶段1：最小原型（核心验证，单机就能跑，不需要多卡，重点验证向量空间对齐逻辑）
目标：验证三件事：
①簇内/簇间损失可以维持扇区分布；
②残差增量只能小幅修改向量，不会跨簇；
③本体向量可以和LLM的token embedding建立对齐。
硬件：普通PC（带一张消费级显卡，16G显存足够）
实现内容：
1. 构造小规模三元组训练集（实体A，谓词R，实体B），可以先用RCC8，再少量通用领域样本，不用上万条，几百~几千条足够原型。
2. 实现轻量残差嵌入模型（参考RotatE复数旋转架构，增加残差、簇原型更新、4项loss）
    - 模型很小，不是大Transformer，只是KG嵌入模型；
    - 约束：增量F(x)做范数裁剪，禁止跨扇区跳跃。
3. 加载开源LLM（千问7B/1.5B，本地推理），提取谓词对应的token embedding。
4. 训练对齐投影矩阵$W_{align}$，最小化$L_{alignment}$。
5. 测试：输入一句描述`通孔穿过焊盘`，系统第一步粗检索找到【空间拓扑簇】，第二步精确匹配谓词`穿过`，第三步把本体向量投影送入LLM。

**阶段1的核心目标：验证你的整套数学机制是否成立。**
如果原型验证失败，在这里调整本体规则、损失函数，成本最低。

## 阶段2：扩容与通用化（原型验证通过后）
1. 扩充谓词库，从PCB拓展到通用领域（物理对象、抽象概念、因果、模态判断）。
2. 扩充三元组数据集，引入Wikidata、WordNet的公开三元组。
3. 优化范畴检索：优化簇原型检索，提升粗分类速度。
4. 对齐优化：微调对齐矩阵，保证自然语言输入稳定映射到本体空间。
> 这一步Schema子系统B成熟，可以脱离PCB，变成通用本体系统。

## 阶段3：完整系统融合（最后一步）
把三部分完整串联：
输入自然语言 → 粗范畴检索（Schema-B） → 锁定簇扇区 → 精确谓词匹配 → 本体向量投影 → 送入Transformer大模型做推理/代码生成/Schema校验。
增加闭环：大模型输出结果，可以反向提取实体与关系，回流到本体系统做校验、增量更新（依然遵守残差小幅修改规则，不破坏顶层Schema）。

# 关键风险提前说明
1. **对齐冲突**：LLM学到的语义，会试图拉扯本体向量；而$L_{intra}/L_{inter}$会强行守住簇的拓扑。两者会互相拉扯。原型阶段要观察这种冲突，调整loss各项权重。
2. **谓词歧义**：同一个动词在不同场景属于不同范畴。例如“包含”：物理空间包含、集合逻辑包含，需要拆成两个独立谓词，分配到不同簇。
3. **规模上限**：当谓词数量极大，二维复平面（单位圆）表达能力会不足。后续可以升级到高维复数空间（类似RoPE多子载波），原型先用二维复平面。
