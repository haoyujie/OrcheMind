# 选 TransformerLens 来讲（网上拆解大模型视频最常用，适配千问开源）
> 核心定位：**给Transformer做“带钩子的包装器”**。它不直接读裸内存字节，而是在PyTorch模型的每个模块入口/出口插入回调函数。每一段算子跑完，把**该模块的张量（计算结果）拷贝出来存住**，带上语义标签：这是第N层的q、k、v、注意力分数、残差、MLP输入输出。

## 一、它能输出什么（有语义的张量，不是裸内存块）
以一层Self-Attention为例，前向推理一条prompt时，你可以拿到：
1. `q`：query张量，shape `[batch, heads, seq_len, d_k]`
    每个头里，每个token的查询向量；含义：**这个token要去“找什么信息”**
2. `k`：key张量，同shape；含义：**每个token向外暴露的“索引标签”**
3. `v`：value张量；含义：**匹配成功后，要提取的信息内容**
4. `attn_scores`：QK相乘还没softmax的原始分数矩阵 `[batch, heads, seq_q, seq_k]`
    数值代表：token i对token j的**原始匹配强度**
5. `attn_pattern`：softmax+mask后的注意力权重矩阵（0~1）
    热力图最常用：看哪个token在关注前面哪个token
6. `attn_output`：`attn_pattern @ v`，注意力加权求和后的输出
7. 残差流（residual stream）：**最核心的一条主线**
    - 层输入残差（进入该transformer块之前）
    - 注意力模块输出，加到残差上之后的残差
    - MLP输出，再加回残差之后的残差（进入下一层）
    > 残差流是整个LLM的“信息传送带”，所有事实、逻辑、指代都编码在这条向量里。
8. MLP内部：MLP输入、gate、up、down投影后的张量，激活后的中间值。

除此之外：
- 可以拿到**每个token位置**对应的所有中间张量；
- 可以导出成numpy数组，存成npy，或者转csv；
- 直接画热力图（attention矩阵）、PCA/t-SNE降维看向量聚类；
- 看数值异常：NaN、inf、数值爆炸、数值饱和。

> 区分：裸内存块只是一堆float，你不知道哪块对应q哪块对应v；TransformerLens**给张量打上模块、层、头、token位置的语义标签**。这就是它比直接dump显存强的地方。

## 二、可以调整哪些东西（两类：模型权重 / 推理时的中间激活）
### 1）模型权重（永久改动，改完要重新加载模型）
- 某一层/某个注意力头的 `W_q, W_k, W_v, W_o` 权重矩阵
- MLP的 `W_up, W_gate, W_down`
- LayerNorm的weight/bias
> 修改权重=修改模型本身；改完之后**所有推理都会受影响**。成本高，一般做剪枝、消融实验（ablation）：比如把第3层第2头权重置零，看模型能力掉多少。

### 2）**激活干预（临时改动，单次推理生效，最常用！网上“改模型想法”都是这个）**
在**前向推理中途**，在某个模块输出之后，直接改写张量的值，只影响这一次生成，权重文件不变。
典型操作：
1. 残差流注入：在第N层残差加上一个 steering vector（导向向量），强行让残差向量往某个方向偏移，改变后续所有层的计算。
2. 注意力头干预：把某个头的attn_output直接置0 / 替换成别的张量，**屏蔽这个头的作用**。
3. 替换Q/K/V：直接覆盖某一层某个头的q或v张量，强制让这一层“看到你指定的向量”。
4. 屏蔽特定token的注意力：修改attn_scores，强制降低token A对token B的关注度。

> 这就是你问的：跑一次，改参数/改中间张量，再跑一次做对比。

## 三、两次运行结果怎么比对（A/B对比）
标准流程：
1. **基准跑（run A）**：原始模型，无干预，开启cache所有中间张量，保存全套张量到磁盘（npy文件，带路径标记：`layer.5.attn.q`、`layer.5.residual_post_attn`）。
2. **干预跑（run B）**：只改你选定的一项（例如：在layer5残差注入向量；或者把第2头Wv置零），**其他所有条件严格固定**：
    - 完全相同prompt；
    - 相同随机种子（确保采样确定性，关闭temperature随机采样，用greedy解码）；
    - 相同batch、上下文长度。
3. 按**同名张量做逐元素对比**：
    - 逐元素差值：`diff = tensor_B - tensor_A`
    - 均方误差MSE、L2范数、最大绝对误差；
    - 可视化：热力图对比attn_pattern，看注意力哪些位置变了；
    - 逐层统计：看**改动从哪一层开始扩散**，影响多大，哪几层几乎不受影响。

### 典型现象
- 如果你只干预第5层残差：
  - 0~4层张量：A和B几乎完全一致；
  - 第5层之后：残差、后续所有层的q/k/v、注意力、MLP全部开始出现偏差，偏差沿着残差流向后传播；
  - 前面层不受影响，这是一个非常强的验证。

> 关键点：**必须固定采样为greedy**。如果开temperature，token采样会引入随机噪声，你分不清差异是来自干预，还是随机采样。

## 四、极简伪代码（TransformerLens，千问示例）
```python
from transformer_lens import HookedTransformer
import torch

# 加载千问开源模型
model = HookedTransformer.from_pretrained("Qwen/Qwen-7B-Chat")
prompt = "1+1等于几"

# ========== Run A：基准，捕获全部中间激活 ==========
cache_A, _ = model.run_with_cache(prompt)
# cache_A是字典，key是模块名字："blocks.5.attn.q"，value就是对应张量

# ========== Run B：干预示例：在第5层残差加偏移向量 ==========
def hook_add_resid(value, hook):
    steer_vec = torch.randn_like(value) * 0.1
    return value + steer_vec

# 注册钩子，只在blocks.5.hook_resid_post触发
hooks = [("blocks.5.hook_resid_post", hook_add_resid)]
cache_B, _ = model.run_with_cache(prompt, fwd_hooks=hooks)

# ========== 比对：取第6层Q张量做差值 ==========
q_A = cache_A["blocks.6.attn.q"]
q_B = cache_B["blocks.6.attn.q"]
diff = q_B - q_A
print("最大差值：", diff.abs().max())
```

## 五、边界（哪些东西它看不到）
1. CUDA内核里的临时寄存器、kernel中间缓存、显存碎片——看不到；只看模型模块的**输入输出张量**；
2. 它不会自动告诉你“这个向量代表什么概念”；**只提供数值，解释靠人做**。比如你看到注意力矩阵某头强烈关注前面的数字token，是你自己去解读含义，工具只输出矩阵。
3. 不能直接看到权重更新（训练阶段梯度）；想看梯度要额外hook backward。

## 六、典型实验例子帮你理解
目标：验证“某个注意力头负责指代”
1. A：原始模型，输入句子“小明去公园，他很开心”，记录所有层注意力矩阵；观察某个头会把“他”对齐到“小明”。
2. B：在该层，把这个头的输出置零。
3. 对比A/B：
    - 这个头的attn_pattern消失；
    - 模型输出从“小明很开心”变成错误指代；
    - 逐层看残差流的差异，定位信息丢失发生在哪一层。
