# 总损失公式
$$L_{total}=L_{task}+L_{intra}+L_{inter}+L_{alignment}$$
逐项拆开解释，每一项的作用，正向/反向如何约束个体动词和簇。

## 1. $L_{task}$：主任务损失（本体关系预测，核心任务）
目标：给定实体对（通孔，焊盘），预测二者之间的关系动词（穿过）。
输入：实体向量 + 关系动词向量$\boldsymbol r_{verb}$；标签是真值关系。
- 正向：计算实体对与各个动词向量的匹配得分，预测关系。
- 反向：预测错误时，产生梯度，微调动词向量$\boldsymbol r_{verb}$。
> 这一项负责保证：**单个动词的角度向量，可以精准索引、识别具体关系**。也就是你说的：能够精确指向下一层。

## 2. $L_{intra}$：簇内损失（同簇动词，拉近，近义词约束）
> 作用：$L_{intra}=\sum_{(r_i,r_j)\in同一簇} \big[ 1 - sim(\boldsymbol r_i,\boldsymbol r_j) \big]$里面，动词之间向量距离要小。
> 例如簇=【空间关系】：`穿过`、`贯穿`、`包围`，互相之间余弦相似度要高。

$$L_{intra}=\sum_{(r_i,r_j)\in$L_{intra}=\sum_{(r_i,r_j)\in同一簇} \big[ 1 - sim(\boldsymbol r_i,\boldsymbol r_j) \big]$} \big[ 1 - sim(\boldsymbol r_i,\boldsymbol r_j) \big]$$
$sim$ = 余弦相似度。
- 正向：评估同簇动词互相靠近的程度
- 反向：如果同簇两个动词在训练中被拉开距离，loss上升，梯度会把它们拉回靠近。

> 注意：这里**不是直接修改簇原型**，是约束簇内个体动词。

## 3. $L_{inter}$：簇间损失（不同簇，互相推远，簇边界隔离）
> 作用：不同范畴簇，向量必须拉开距离，防止跨扇区混淆。
> 空间簇 vs 归属簇，相似度要尽量低。

$$L_{inter}=\sum_{r_i\in簇A,\ r_j\in簇B,A\neq B}\ max\big(0,\ sim(\boldsymbol r_i,\boldsymbol r_j)-\delta\big)$$
$\delta$ 是阈值（例如0.2）：
- 两个不同簇向量相似度超过$\delta$，就会产生loss，惩罚；
- 相似度本来就很低，loss为0，不干预。

👉 $L_{intra}+L_{inter}$ 合起来，就是**簇的分类约束**。
训练的时候，它强制：
✅ 同簇动词聚集在扇区内
✅ 簇与簇之间留出间隔，不会混在一起
> 运行时，第一层领域定位器，就是拿输入表征，去和**簇原型向量**做相似度检索，快速选出属于哪一簇。

### 簇原型向量怎么来（和动词向量同步训练）
每个簇的原型向量 $\boldsymbol r_{cluster}$，初始化为簇内所有动词初始向量的平均值。
每一轮训练，**原型跟着动词一起更新**：
$$\boldsymbol r_{cluster}^{new} = \alpha \cdot \boldsymbol r_{cluster}^{old} + (1-\alpha) \cdot mean(\boldsymbol r_{verb\in cluster})$$
$\alpha$ 是平滑系数，0.9~0.99，防止原型剧烈抖动。
> 簇原型是独立向量，**可以直接参与检索**，不再只是一个loss里的规则。
> 正向推理：输入向量和全部簇原型做相似度，选出得分最高的簇，完成第一层粗定位。

## 4. $L_{alignment}$：对齐损失（最关键，连接本体小模型与大模型）
目标：让本体里面的动词向量，和大模型（千问这类Transformer）里对应词语的token嵌入，映射到同一个地址空间。
$$L_{alignment}= \big\| \boldsymbol r_{verb\_ontology} - \boldsymbol W_{align} \cdot \boldsymbol r_{verb\_llm} \big\|_2^2$$
- $\boldsymbol r_{verb\_ontology}$：本体层的动词角度向量（我们自己的二维/高维圆环表征）
- $\boldsymbol r_{verb\_llm}$：大模型提取出来`穿过`、`连接`对应的token embedding
- $W_{align}$：可学习的对齐投影矩阵

正向：把大模型的词嵌入投影到本体的向量空间，计算和本体动词向量的距离。
反向：梯度同时更新本体动词向量、对齐矩阵。
> 效果：两套表征空间打通。大模型输出的语义，可以翻译成本体的角度向量；本体的关系向量也可以送入大模型。
> 实现你说的：本体小模型 和 Transformer大模型 统一地址编码。

# 残差链路在这里如何和这套Loss配合（重点）
每一层动词向量更新：
$$\boldsymbol r_{verb}^{l+1} = \boldsymbol r_{verb}^{l} + F(\boldsymbol r_{verb}^{l})$$
加上归一化，保证落在单位圆。
$F(\boldsymbol r_{verb}^{l})$ 是本层学习增量，增量范数做上限裁剪，**禁止大幅度跳跃**。

反向梯度来源：梯度来自上面4个loss总和。
- $L_{task}$：保证单个动词识别准确
- $L_{intra}/L_{inter}$：约束簇的聚集和边界，保证簇原型稳定
- $L_{alignment}$：保持和大模型嵌入空间对齐

> 残差负责：**父层的角度信息不会被覆盖，只能叠加微小增量**
> Loss四项联合约束：**增量修改不能破坏簇的拓扑，不能破坏和大模型的对齐**

# 训练的两个阶段（推荐分两阶段训练，稳定性远高于一次性联合训练）
## 阶段1：Schema预热（人工先验打底）
1. 人工定义全部动词，划分簇；
2. 给每个动词分配初始角度，同簇放在连续扇区；
3. 初始化簇原型；
4. 只启用 $L_{intra}+L_{inter}$，冻结对齐矩阵$W_{align}$。
> 目的：先把本体的簇拓扑固定下来，建立好圆环上的分布。**人定义的Schema优先，模型只做微调，不推翻本体结构**。

## 阶段2：联合微调（本体 ↔ LLM对齐）
全部loss打开：$L_{task}+L_{intra}+L_{inter}+L_{alignment}$
- 本体动词、簇原型、对齐矩阵一起更新；
- 残差增量依然带幅度限制，不允许动词跨扇区跳到别的簇；
- 反向传播时，任何更新同时满足4项约束。

# 运行时完整流程（对应你设想的三段式）
1. **第一层（簇检索）**
输入文本 → 提取表征 → 和全部簇原型向量做相似度计算 → 选出Top1簇。
> 快速粗定位，直接锁定扇区，不用遍历全部一万个动词。

2. **第二层（本体谓词匹配）**
限定在选定簇内部，遍历该簇内所有动词向量，做相似度检索，选出精确关系动词（`穿过`）。

3. **第三层（接入Transformer大模型）**
把选中的实体向量 + 动词本体向量，经过对齐投影$W_{align}$，映射到大模型的token地址空间，送入Transformer做推理、代码生成、Schema校验。

# 风险点
1. 簇原型是动词的滑动平均，**簇原型本身不会自动生成新簇**。新动词只能人工归入现有簇，符合你的Schema人为可控的目标；
2. 残差+归一化+增量裁剪，保证训练时动词不会跨扇区逃逸；
3. $L_{alignment}$会带来拉扯：大模型语义会试图拉扯本体向量。$L_{intra}/L_{inter}$会抵抗这种拉扯，守住本体簇结构。这就是你要的制衡。

# 一句话总结
簇不再只是loss里的约束规则，**簇原型是独立向量，可以直接检索**。总损失拆成四项，同时约束：
单个动词识别精度、簇内聚集、簇间隔离、本体与大模型嵌入空间对齐；
分两阶段训练，先用人工Schema打底固定簇拓扑，再联合对齐大模型；残差链路保证每层动词角度信息保留，增量修改被限制，不会打散预先定义的扇区布局。
