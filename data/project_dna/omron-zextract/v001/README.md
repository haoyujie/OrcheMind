# Omron Z 抽出 DNA v001

**冻结。** 下一版见 `../v002/`。

只登记一件事：按信号层添加 Z 抽出。规则参数表仍以 `zextract-rules.dna.csv` 为运行时真源，本版不把 CSV 行抄进训练三元组。

- 信号层由走线、焊盘、覆铜组成。
- 刀具绑定以某一层为这次抽出的目的层。
- 放置在该层已有几何上构建窗，并产生 Z 窗。
- 窗属于该层，并挂接宿主焊盘。
- 规则约束放置。窗构成 PCB 的 WIN 296。

## 坐标能力（本版结论）

V03 还不能把一份新本体集合送进去，就反查出簇和坐标。本版能做的反向查询是声明坐标上的最近邻，见 `coordinates.json`。
