# Omron PCB 结构 DNA v001

二维码个体，料号样例 `HB1318PFF83A2-X10-300` 的 `[PRT 3-1]` / `2DBD_644`。

- 种类 256。第一个 ISU `[ISU 3-1-1-1]` 是占位，不进 INSP。
- 检测单元是 `[ISU 3-1-1-2]`（1462），落入硬件检查窗 5。
- 窗 84 从属于算法组 11；窗 85 从属于算法组 14；组 14 组成 Mark 2054 与 TH 焊盘 2020。

不修改 `omron-zextract` 的 v001 / v002。需求只描述 bug 时版本不变；增加类或边时另建下一版。
