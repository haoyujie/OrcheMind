# 02 知识层

## 三层：输入的粒子、连接、得到的结构

| 层 | 含义 | PCB 例子 |
|---|---|---|
| 粒子（Particle） | 输入。在当前焦点里不再往下分的对象 | 孔、焊盘、铜层、钻刀 |
| 连接（Connection） | 把粒子组织起来的中间对象：事件、配对、绑定、规则参数 | 钻孔事件、焊盘对、刀具绑定 |
| 结构（Structure） | 得到的整体：组合的结果、种类与规范 | 板、叠层、环根、规则集 |

做法与 ISO 把七层简化为少数几层相同：每层只和相邻层打交道，上层包住下层、把它挡在后面。粒子只有经过连接，才进入结构。

**层间连接少而贵。** 同层之内连接多；跨层的连接代价高、责任重，所以少，但不可缺。呈现上跨层边画成竖线；数据上每一条都由裁判检查。

## 层与权重是两个量

借用波普尔的模式：同一条信息被越多个体认可，层次越高。但"被引用得多"不等于"层次高"——原子和上帝都被人人引用。所以拆成两个量：

- **层**（level）由结构角色决定：按动词把边定向为"输入 → 输出"，再算广义营养级。
- **权重**（weight）由认可度决定：有多少个不同的认可方引用这个节点。

| | 原子（底层粒子） | 上帝（顶层结构） |
|---|---|---|
| 层 | 低（营养级约 0） | 高（营养级最大） |
| 权重 | 高 | 高 |
| 边的角色 | 作为部分被许多整体包含 | 作为种类或规范统摄许多对象 |
| Resnik 信息量 | 高（具体，部分学的叶子） | 接近 0（最一般，分类学的根） |

权重相同，层把它们分开；信息量是第三个佐证。

### 边的方向（封闭表）

方向表是封闭的：不在表里的动词不参与定层，只算认可度。这样新加一个动词不会悄悄改变分层。

| 动词 | 输入 | 输出 |
|---|---|---|
| `part_of`、`constitutes`、`subordinate_to`、`causes`、`participates_in`、`heads`、子类→父类 | 源 | 目标 |
| `composes`、`constructs_from`、`aims_at`、`constrains`、`forbids`、`inheres_in`、`abstracted_from` | 目标 | 源 |
| `corresponds`、`accompanies`、RCC8（`PO`、`EC`、`EQ` …）、`appearance_of` | 对等，不定向 | |

`abstracted_from` 的目标（世界叶子）是输入：视图是表示，表示比它所表示的东西高一层。

### 算法

1. 只取焦点范围内的类和定向边（见下文"最小粒度"）。
2. 广义营养级（MacKay、Johnson、Sansom 2020）：令 W 为定向边权矩阵，\(u = w^{in} + w^{out}\)，\(v = w^{in} - w^{out}\)，解
   \[ (\mathrm{diag}(u) - W - W^\top)\, h = v \]
   每个弱连通分量单独求解，分量内最小值平移到 0。
3. 归一化 \(t = h / \max h\)（分量内）。
4. 定层：
   - **焦点内没有输入的类是粒子**——这就是最小粒度的定义（见下文）。广义营养级不会把源点钉在 0（例：板轮廓只有一条 `part_of` 指向板，\(t\) 却有 0.67），所以粒子不按阈值判，按"有无输入"判。
   - 有输入的类：\(t \ge 2/3\) 为结构，否则为连接。
   - 没有任何定向边的孤立类记为粒子，并标"未定"。
5. **四因**：质料因由多个元素组成的类必有输入，所以不会是粒子，至少在大层中部（连接层）。`MaterialInputs` 记下质料元素数，供呈现和审阅。
6. 营养不一致度 \(F_0 = \overline{(h_{out} - h_{in} - 1)^2}\) 作为整体指标输出：越小，层次越清楚。

备选是 SpringRank（De Bacco、Larremore、Moore 2018），在环多的图上更稳；接口相同，可替换。

### 权重

认可方 = 引用这个节点的不同主体。最小的需求方粒度是人；当前数据里还没有人，所以先用以下几类代替，以后再细到人：

- 与它有边相连的不同类（任一方向，含它的子类）；
- 列出它的不同结构。

以后加上：导入它的不同文件（模块），再细到具体的人。

权重 = \(\log_2(1 + \text{认可方数})\)，按焦点范围归一化到 [0, 1]。

## 最小粒度

最小粒度不是绝对的，它在每个焦点的上下文里定义：**大层分界之上第一层里的通用对象**，就是最小粒度。

| 焦点 | 大层分界之下 | 最小粒度 |
|---|---|---|
| 量子力学 | — | 弦 |
| 物质 | 量子 | 原子 |
| 蛋白质 | 化学 | 基因 |
| 生物 | 分子 | 细胞 |
| 社会 | 生物 | 人 |
| PCB 实物 | 材料 | 孔、焊盘、铜层 |

实现上，"大层分界"就是焦点范围的边界（一个宇宙，或一个结构）。焦点内部、输入全部来自分界外（或没有输入）的对象，就是粒子层，也就是这个焦点的最小粒度。换一个焦点，同一个对象可以从粒子变成结构。

**四因的启发**：如果这次的质料因由多种元素组成，说明这个四元组处在大层的中间，而不是底层附近。算法第 4 步就是这条规则。

## 以后：扩展到七层

三层是七层的压缩。扩展时不改算法，只在营养级上标出"大层分界"（营养级上的大间隙，或范围边界），每个大层内部再分粒子、连接、结构。接口上层号带一个"所在大层"的字段即可。
